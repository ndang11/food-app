# 🏷 Royal-Food

> A modern food ordering web application that allows users to browse meals, add favorites, and manage their shopping cart.

---

## 📌 Problem Statement

Many food delivery platforms have complex interfaces and lack personalization. This application provides a simple, intuitive interface for users to discover meals and manage their orders, while allowing admins to easily manage the food catalog.

---

## 🎯 Project Goals

- Display a variety of meals with images, prices, and descriptions
- Allow users to mark meals as favorites
- Provide a shopping cart for ordering food items
- Enable admin users to add, update, and delete food items
- Provide a responsive design that works on all devices

---

## 🛠 Tech Stack

**Frontend:**  
- React  
- CSS Modules  
- React Router  

**State Management:**  
- React Context API  

**Other Tools:**  
- Vite (Build tool)
- Git & GitHub  

---

## 🖥 Features

- Browse food menu with images and prices
- Search and filter food items
- Mark meals as favorites with heart icon
- Add items to cart and manage quantities
- Admin dashboard for food management
- Responsive design for mobile, desktop and tablet

## ⚙ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/ndang11/food-app.git
cd food-app
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
