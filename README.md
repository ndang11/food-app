Project Description:
This App is a simple React.js food management, where users can view a variety of different meals and their prices also an Admin user dashboard where a users can also add, update and delete food items.Furthermore we also have a cart basket where users can add to their list of items and also increase and decrease the number of items the need to purchase.

#About 
This App was build with Vite, React Context API, React Router for fast deployment.
